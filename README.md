# HOLO, version démo

Application web de gestion pour revendeur de cartes Pokémon : stock, achats, ventes, lives Whatnot, trésorerie et to-do.

Cette version est une démo : toutes les données sont fictives, générées au premier lancement, et restent dans le navigateur du visiteur. Aucune donnée n'est envoyée en ligne.

## Lancer

    npm start

Le serveur écoute sur le port `PORT`, ou 8080 par défaut. Aucune dépendance à installer.

## Déployer sur Clever Cloud

Créer une application **Node.js**, puis pousser ce dossier. Clever Cloud lance `npm start` automatiquement.
